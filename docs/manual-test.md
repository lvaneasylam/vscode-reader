# 手动验证清单（F5 Extension Development Host）

启动方式：VSCode 打开 `packages/vscode-ext`，F5。在扩展开发宿主中操作。

## 1. 书源导入与管理
- [ ] 命令面板 → `小说阅读: 导入书源（本地文件）` → 选择书源 JSON → 提示「新增 N、更新 M」
- [ ] 含 XPath/音频源的合集 → 提示兼容性警告，「查看警告」可列出明细
- [ ] `小说阅读: 管理书源` → 列表选择 → 启用/禁用/删除生效
- [ ] 管理书源 → 「编辑」→ 编辑器打开该书源 JSON → 修改规则 → `Cmd+S` → 提示「书源已更新」→ 搜索行为随之变化
- [ ] 编辑时故意破坏 JSON 再保存 → 报错「书源 JSON 未生效」且原书源不受影响
- [ ] `小说阅读: 校验书源` → 进度通知逐个检测 → 结果面板展示失败明细（错误原因 + 耗时）→ 「禁用全部失败书源」生效

## 2. 搜索与书架
- [ ] `小说阅读: 搜索书籍` → 选书源 → 输关键字 → 结果 QuickPick 展示书名/作者/最新章节
- [ ] 选中一本书 → 侧边栏「小说阅读」书架出现该书并展开目录
- [ ] 状态栏出现 `📖 书名 · 1/N`

## 3. 面板模式（默认）
- [ ] 底部面板出现「小说阅读」标签，正文多行显示
- [ ] 「下一章 →」/「← 上一章」按钮工作
- [ ] `Alt+→` / `Alt+←` 翻章工作
- [ ] 章节树点击任意章节 → 面板跳转
- [ ] 状态栏导航点击 → 章节选择器 → 输入过滤 → 跳转

## 4. 状态栏模式
- [ ] `小说阅读: 切换阅读位置` → 状态栏出现单行正文
- [ ] `Alt+↓` 逐行下移；章末再按 → 自动翻章回行首
- [ ] `Alt+↑` 上移；行首再按 → 上一章末行
- [ ] 再切换回面板模式 → 单行正文消失、面板恢复

## 5. 进度与恢复
- [ ] 阅读至第 N 章后关闭开发宿主 → 重新 F5 → 自动恢复该书第 N 章
- [ ] 书架节点显示进度 `n/N`

## 6. 错误处理
- [ ] 断网翻章 → 面板显示错误条（请求失败信息），恢复网络后可继续
- [ ] 规则失效书源 → 「本章内容为空（规则可能失效）」

## 7. 打包
```bash
cd packages/vscode-ext && npx vsce package --no-dependencies
# 产物 novel-reader-0.1.0.vsix → code --install-extension novel-reader-0.1.0.vsix
```
