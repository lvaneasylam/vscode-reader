# 图标重设计 — 2026-09-23

## 背景

原 `packages/vscode-ext/media/` 图标为单色（currentColor）"人 + 书"造型，市场列表中辨识度低。

## 设计决策

| 决策点 | 选择 | 备选（已否决） |
|---|---|---|
| 视觉概念 | 打开的书 + 渐变页 + 双飘页（变体 A） | 书 + 光源；书 + 彩色书签；沿用旧轮廓上色 |
| 色彩 | 左页暖（#FBBF24→#F97316）、右页冷（#6366F1→#38BDF8） | 紫蓝青单渐变；落日暖色 |
| 背景 | 透明 | 深色圆角底；渐变底 |
| 细节 | 白色半透明文字线 ×6、中缝高光、深靛书壳（#4338CA→#312E81） | 无文字线极简版 |

冷色象征沉浸、暖色象征故事热情，双色对比保证小尺寸下的轮廓辨识。

## 落地

- `media/icon.svg` — 矢量源（1024 viewBox），被 `package.json` 活动栏视图容器引用
- `media/icon.png` — 256×256 RGBA 透明 PNG（Chrome headless 渲染），市场图标

## 验证记录

- alpha：71.1% 全透明像素，透明背景生效
- 多尺寸：128/48px（marketplace、活动栏实际尺寸）清晰；32px 可辨；16px 模糊（无使用场景，不制简化版）
