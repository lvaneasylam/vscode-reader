# 墨遥·阅山行 · JetBrains 版

在 IntelliJ / PhpStorm / GoLand 等 IDE 里用书源看小说的摸鱼插件。与 [VSCode 版](../../README.md) 同引擎（Node sidecar 复用书源解析核心），功能对齐主线版本。

## 安装

```
Settings → Plugins → ⚙️ → Install Plugin from Disk
→ packages/jetbrains/build/distributions/novel-reader-jetbrains-<版本>.zip
→ 重启 IDE
```

> 每轮修复版本号都会递增，安装后请在 Plugins 页确认版本号，避免装到旧包。

## 设置入口（重要）

**`Settings (⌘,) → Tools → 墨遥·阅山行`**，或设置搜索框直接搜 **「墨遥」**。

| 分组 | 配置项 |
|---|---|
| 阅读外观 | 字号 / 行高 / 正文宽度 / 字体名 / 字体文件 / 背景色 / 文字色 |
| 阅读行为 | 章末自动翻章 / 状态栏显示宽度 / 章节缓存数 / 向后预加载章节数 |
| 登录与网络 | token 直登字段名 / 书源请求超时（毫秒）/ 信任所有 HTTPS 证书 |
| 运行时 | Node.js 路径（空 = 自动探测） |

## 快速上手

1. **导入书源**：`Tools 菜单 → 墨遥·阅山行 → 导入书源`（本地文件 / URL / 剪贴板，支持合集）
2. **登录**（需认证的书源）：`Tools → 墨遥·阅山行 → 书源登录`，三种方式：
   - 表单登录（账号密码，自动记忆）
   - 凭据直登（多字段：`token=…; uid=…; session=…` 分号分隔一次配齐；不带字段名的值写入设置里配置的默认字段）
   - 手动 Cookie（整行 Cookie 粘贴）
3. **找书**：工具窗 **发现** 页选分类浏览，或 `Tools → 墨遥·阅山行 → 搜索书籍`
4. **阅读**：书架双击书/章节 → 自动跳到阅读页

## 交互

| 操作 | 效果 |
|---|---|
| 双击书架的书 / 章节 | 打开并跳到阅读页（章节直达） |
| 单击正文某一行 | 当前行（蓝色竖条高亮）切换到该行，页面不滚动 |
| `Alt+→` / `Alt+←` | 下一章 / 上一章 |
| `Alt+↓` / `Alt+↑` | 下一行 / 上一行（长行自动分段） |
| `Ctrl+Alt+B`（Mac `⌘⌥B`） | 老板键：一键隐藏/恢复阅读界面 |
| 书架右键 | 刷新目录 / 定位正在读的章节 / 从书架移除 |

「当前行」= 阅读进度锚点（深色底 + 左侧蓝条），IDE 重启后从这里恢复。

## 运行要求与疑难

- **Node.js**：本机需已安装。自动探测 homebrew / volta / fnm / nvmd / nvm；找不到时到设置页「运行时 → Node.js 路径」手动指定（终端 `which node` 的路径）。
- **数据目录**：`~/Library/Application Support/JetBrains/<IDE>/novel-reader/`（书源 / 书架 / 目录缓存 / 登录态）。重装插件不会清数据；数据异常时删除该目录即可重置。
- **排查**：`idea.log` 搜索 `[sidecar]` 可看到全部引擎请求/响应日志。

## 与 VSCode 版的功能差异

JetBrains 版暂未实现：书源管理器（启用/禁用/编辑）、书源批量校验、书源导出。其余主流程功能已对齐。
